# AAT — Autonomous YouTube Shorts Engine

Automated YouTube Shorts compilation, forensic channel analytics, and publishing pipeline powered by the Gemini 3.8 Flash Multimodal Pool, FFmpeg, and Telegram approval workflows.

## Features
- **Discovery:** Finds raw single-scene clips and filters out pre-made compilations.
- **Forensic YouTube Shorts Analytics:** Audits every published video's velocity, retention %, traffic sources, and audience geography to evolve ranking and packaging tactics.
- **Multimodal AI Scoring:** Watches video + audio streams to rank the top 5 moments (`#5` to `#1`) with full climax payoffs and dynamic titles.
- **Transformative Rendering:** Builds 9:16 vertical Shorts (`1080x1920`, `-14 LUFS` normalized audio, clean progressive 1-to-5 ranking list).
- **Telegram Approval & YouTube API:** Sends rendered previews to Telegram for 1-tap publishing via YouTube Data API v3.
